## 📊 TREND ANALYSIS ALGORITHM

### Signal Generation Process
```
1. Fetch OHLC Data
   └─ Multiple timeframes

2. Calculate Indicators
   ├─ SMA Crossovers
   ├─ RSI Levels
   ├─ MACD Divergence
   ├─ Bollinger Band Position
   └─ ATR Volatility

3. Generate Signals
   ├─ BULLISH: SMA9>SMA20, RSI>50, MACD>Signal
   ├─ BEARISH: SMA9<SMA20, RSI<50, MACD<Signal
   └─ NEUTRAL: No clear signal

4. Combine Multi-Timeframe Signals
   └─ Calculate confidence score

5. Place Order
   └─ If conditions met and confidence high
```

### Order Execution
```
Signal Generated
    ↓
Calculate Entry Price
    ↓
Calculate SL = Entry - 1%
Calculate Target = Entry + 2%
    ↓
Place Bracket Order
    ├─ Main Order
    ├─ Stop Loss Leg
    └─ Target Leg
    ↓
Monitor Position
    ↓
Exit when:
├─ Target hit ✓
├─ Stop Loss hit ✗
└─ Time limit reached
    ↓
Record Trade & Update P&L
```
